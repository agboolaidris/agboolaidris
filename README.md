## 👋 About me

I'm a **Software Engineer** based in Lagos, Nigeria with **5+ years** of experience building web, mobile, and backend systems. I specialise in turning complex business operations — supply chains, insurance, distribution — into reliable, easy-to-use software.

- 📱 Built **Ceelah**, an offline-first React Native / Expo app for agro-commodity traceability and EUDR compliance — live on the App Store
- 🏢 Shipped full-stack **ERP systems** for agro-commodity trading, insurance broking, and beverage distribution
- 🤖 Currently exploring **AI-powered products** with the Vercel AI SDK, OpenAI and Anthropic APIs
- 💬 Ask me about offline sync, React Native performance, Mapbox, or NestJS architecture
